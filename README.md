# 🌍 Smart Trip Planner – Multi-Agent AI System

Smart Trip Planner is an **AI-powered travel planning assistant** that helps users discover tourist places, weather, and travel insights for any destination in the world.

The system uses **multiple agents** and open APIs to provide intelligent travel suggestions based on user queries.

Example:

```
I'm going to Mysuru, let's plan my trip.
```

The AI responds with tourist places, attractions, and travel information.

---

# ✨ Features

* 🌍 AI travel assistant for any destination
* 🗺️ Discover tourist attractions
* 🌦️ Get location weather information
* 📍 Geocoding for destination lookup
* 🤖 Multi-agent AI workflow
* 💬 Natural language trip planning
* 🎨 Clean and modern UI

---

# 🧠 How It Works

1️⃣ User enters travel plan or destination
2️⃣ System extracts location from the request
3️⃣ Geocoding service finds coordinates
4️⃣ Weather API fetches climate information
5️⃣ Places API returns tourist attractions
6️⃣ AI combines everything into travel suggestions

# ⚙️ Installation

### Clone the repository

```
git clone https://github.com/Lingu17/tourist-system.git
```

### Navigate to project folder

```
cd tourist-system
```

### Create virtual environment

```
python -m venv venv
```

### Activate environment

Windows

```
venv\Scripts\activate
```

### Install dependencies

```
pip install -r requirements.txt
```

---

# ▶️ Run the Application

```
python app.py
```

Open in browser:

```
http://127.0.0.1:5000
```
